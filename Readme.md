# 🍔 Pojos Hermanos

Projeto de desenvolvimento de um site para um restaurante fictício, criado com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web.

## 📌 Sobre o projeto

O Pojos Hermanos é um projeto de site institucional e comercial para um restaurante, com foco na apresentação do estabelecimento, divulgação do cardápio e navegação entre suas páginas.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 📂 Estrutura do projeto

```text
Projeto-Restaurante/
│
├── index.html
│
├── PAGES/
│   ├── cardapio.html
│   ├── sobre.html
│   ├── pedido.html
│   └── avaliacoes.html
│
├── CSS/
│   └── style.css
│
└── README.md
```

## 📄 Páginas do projeto

- **Início:** página principal do restaurante.
- **Cardápio:** apresentação dos produtos disponíveis.
- **Sobre:** informações sobre o restaurante.
- **Pedidos:** estrutura da página de pedidos.
- **Avaliações:** espaço destinado às avaliações dos clientes.

## 🎯 Objetivos

- Praticar estruturação de páginas com HTML5.
- Aplicar conceitos de HTML semântico.
- Desenvolver navegação entre diferentes páginas.
- Trabalhar organização de arquivos e diretórios.
- Utilizar Git e GitHub para versionamento do projeto.

## 🔧 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/samuelksouza/Projeto-Restaurante.git
```

2. Abra a pasta do projeto no Visual Studio Code.

3. Execute o arquivo `index.html` utilizando a extensão Live Server.
